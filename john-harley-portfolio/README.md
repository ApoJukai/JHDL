# John Harley De Leon Liquid Glass Portfolio

## Setup
1. Install Node.js 18 or newer.
2. Add `profile2.png` and `John-Harley-De-Leon-CV.pdf` to `public/`.
3. Run `npm install`.
4. Run `npm run dev`.
5. For production, run `npm run build`.

## Customize
- Main content: `src/App.jsx`
- Global styles: `src/index.css`
- Replace the placeholder LinkedIn link in `src/App.jsx`.

The viewport is fixed. Only the active content panel scrolls when necessary.
